# LinxtexBot ☁️

Cloudflare-native Telegram bot for generating Instant View pages.

## Getting Started

1. **Install Dependencies**:
   ```bash
   bun install
   ```

2. **Local Development**:
   ```bash
   bun run dev
   ```

3. **Deploy**:
   ```bash
   bun run deploy
   ```

## Stack
- **Framework**: Cloudflare Workers (using Bun)
- **Database**: Cloudflare D1
- **Parser**: @mozilla/readability
- **Platform**: Telegra.ph
